# Path of Building 2 Community

### Build planner and optimizer for Path of Exile

Path of Building 2 Community Edition is the essential tool for Path of Exile theorycrafting. Simulate any build, calculate DPS across skill and gear combinations, and optimize your character before spending a single currency.

<br>

---

## Features

| | |
|:---|:---|
| **Full Build Simulation** | Accurate DPS, defense, and stat calculations for any build concept |
| **Passive Tree** | Interactive skill tree with all nodes, clusters, and jewel sockets |
| **Item Crafting** | Simulate crafted items to find the optimal affixes before spending orbs |
| **Import from PoE** | Import your live character directly from Path of Exile for analysis |
